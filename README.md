# Solo Defender

A 2-D grid-based strategy RPG developed in Unity. Manage resources, upgrade your
settlement, defend from invading enemies and ultimately defeat enemy camps.

## Features
- Enemy AI and detection system
- Combat and enemy attack systems
- Player movement and interaction systems
- Inventory and item management
- Settlement upgrades and resource managment
- Save system

## Tech stack
- Unity
- C#
- Unity Navmesh
- ScriptableObjects

## Technical Highlights
- **Enemy AI:** Field of view detection, player visibility checks
- **Player Systems:** Separate systems for movement, combat, visuals and interactions.
- **Fight System:** an auto battler system in which the player can use one ability 
    per turn: a fighting skill, potions or spells
- **Event-driven communication:** Events used to communicate gameplay changes between different components.
- **Data Management:** ScriptableObjects used to organize and manage gameplay data.
