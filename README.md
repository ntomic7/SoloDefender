# Solo Defender

A 2-D Grid-Based Strategy RPG. Manage resources, upgrade your settlement, defend
from invading enemies and ultimately defeat the enemy camps.

## Features
- Enemy AI system
- Combat and enemy attack systems
- Player movement and interaction systems
- Inventory and item management
- Save system

## Tech stack
- Unity
- C#
- Unity Navmesh
- ScriptableObjects
